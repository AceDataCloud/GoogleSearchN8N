# Brand asset

`source-icon.png` is the 256×256 AceDataCloud Google Search Dify service catalog asset at `https://github.com/AceDataCloud/GoogleSearchDify/blob/main/_assets/icon.png`. Its SHA-256 is `cf8b5ead614e5ef7aed0f0a3de1b490563a3812c00f5328ec66d8efc16a2bfc1`.

The bundled light and dark SVG icons are original vector magnifying-glass artwork using the service catalog's four-color palette. They are not Google's logo. The node fetches no asset at runtime. This integration is maintained by AceDataCloud and is not an official Google package.
